# 公共契约（全项目唯一事实源）

本目录是全项目接口与数据的唯一标准，三人共用。**任何修改必须先同步另外两人，并更新此目录。**

## 文件说明

| 文件 | 内容 | 负责人 |
|---|---|---|
| `risk_schema.json` | 统一风险记录 Schema（所有检测器输出格式） | 成员A（契约负责人） |
| `api_contracts.md` | 服务间 HTTP 接口约定 | 成员A |
| `schema.sql` | 数据库表结构 v1 | 成员C |

## 铁律

1. 接口只增不改：只允许加字段，不允许改已有字段类型。
2. 契约修改必须当天同步另外两人（群通知 + 更新本目录）。
3. `risks.signature` 是全项目去重与复测消警的唯一键，生成规则：`sha256(url + category + title + 关键细节)`。
4. 敏感信息命中内容在 evidence 中必须脱敏（打码），避免二次泄露。
